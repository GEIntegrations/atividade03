PROJETO ACADÊMICO — ESCOLA HORIZONTE
=====================================

Tema: Escola
Estilo: Minimalista e elegante
Tecnologias: HTML5, CSS3 e JavaScript
Observação: Escola, horários e informações são fictícios e demonstrativos.

ESTRUTURA
---------
index.html       Página inicial
conteudo.html    Informações, listas, imagens e formatação de texto
dados.html       Tabela de horários (com CSS interno específico)
cadastro.html    Formulário HTML5
sobre.html       Quinta página: apresentação do projeto
style.css        Folha de estilos externa compartilhada
script.js        Validação e mensagem do formulário
img/             Ilustrações SVG locais utilizadas pelo site

COMO VISUALIZAR
---------------
1. Extraia o arquivo ZIP para uma pasta do computador.
2. Abra a pasta projeto_escola_horizonte.
3. Clique duas vezes em index.html (ou abra-o pelo navegador).
4. Use o menu superior para navegar entre as cinco páginas.

REQUISITOS DO TRABALHO
----------------------
- Todas as páginas possuem DOCTYPE, html, head e body.
- Todas utilizam header, nav, main e footer.
- O menu de navegação aparece em todas as páginas.
- conteudo.html possui h1, h2, h3, strong, em, parágrafos, ol e ul.
- O site possui mais de três imagens locais e todas têm atributo alt.
- Há link externo para o Ministério da Educação, abrindo em nova aba.
- dados.html utiliza table, tr, th e td. A tabela tem CSS interno.
- cadastro.html utiliza campos de texto, email, telefone, data, número,
  select, radio, checkbox, textarea e arquivo, além de validação.
- script.js exibe mensagem após o envio demonstrativo.
- style.css contém estilos externos e regras responsivas.
- Há um exemplo de estilo inline em index.html, no elemento hero-note.

HOSPEDAGEM GRATUITA
-------------------
O site pode ser publicado gratuitamente no GitHub Pages ou Netlify.

Opção GitHub Pages:
1. Crie uma conta em https://github.com/ (se ainda não tiver).
2. Crie um repositório público, por exemplo: escola-horizonte.
3. Envie todos os arquivos e a pasta img para a raiz do repositório.
4. Abra Settings > Pages.
5. Em Build and deployment, escolha Deploy from a branch.
6. Selecione a branch main e a pasta /(root), depois salve.
7. Aguarde a publicação. O GitHub mostrará o endereço público do site
   na própria página Settings > Pages.

Opção Netlify:
1. Acesse https://www.netlify.com/ e crie uma conta.
2. Use a opção de adicionar um novo site por implantação manual.
3. Arraste a pasta do projeto (ou a pasta extraída) para a área indicada.
4. Aguarde a publicação e copie o endereço gerado.
